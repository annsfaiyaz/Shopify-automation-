# Ahsan Faiyaz — Portfolio

Portfolio site for a senior software and AI engineer (SaaS, FinTech, HealthTech).

Built with Next.js (App Router), React, TypeScript and CSS Modules. Tailwind is used only for the html/body classes.

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

Design tokens (colors, fonts) live in `src/app/globals.css`. Components are in `src/components/`, each with a colocated `*.module.css`.

Read `AGENTS.md` before changing code: this Next.js version differs from older releases, and its docs are in `node_modules/next/dist/docs/`.
